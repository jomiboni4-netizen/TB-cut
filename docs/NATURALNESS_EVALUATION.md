# 口播自然度评测基线（合成用例）

## 用途与边界

本文件先固定评测问题和记录格式，供后续相同基线/实验版对比。当前用例均为合成文本，不代表真实素材的准确率。音频电平只能提供边界风险信号；不能单独判断发音是否完整，也不能代替局部回听。语义重复标签由人工/语义审阅确定，不能由字符串相似度直接定案。

## 问题轴 A：切点吞字或截断

每个开头、内部拼接点和结尾分别记录：

- `PASS`：局部回听确认没有切掉音节/词，也没有把依赖上下文的残句留在成片中。
- `RISK`：词级 ASR 时间戳与切点相交、边界附近仍有连续能量，或 ASR/电平对边界判断不一致；须局部回听。
- `FAIL`：回听确认听到半个音节/词，或句子被切断且无法独立理解。
- `UNVERIFIED`：缺少可用音频或局部 ASR；不得当作通过。

机器记录的证据至少包括源范围、输出范围、边界前后局部窗口、词级时间戳覆盖关系、边界电平统计及工具/模型版本。不得把整段 ASR 或素材写进公开报告。

### 合成边界用例

| ID | 合成场景 | 预期标签 | 说明 |
| --- | --- | --- | --- |
| CUT-01 | 切点位于词级 ASR 词的中间 | RISK，回听后应 FAIL 或调整边界 | 时间戳相交是可自动筛查信号 |
| CUT-02 | 词时间戳完整，但边界处语音能量仍持续 | RISK | 可能是 ASR 对齐偏差或词尾被截 |
| CUT-03 | 边界落在稳定静音，完整句意结束 | PASS（仍以可听检查确认） | 静音不是语义闭合证明 |
| CUT-04 | ASR 显示完整词，但回听发现辅音/尾音被切掉 | FAIL | 体现单靠 ASR 时间戳的漏检 |
| CUT-05 | 低音量尾音、环境噪声或伴奏覆盖边界 | UNVERIFIED / RISK | RMS 阈值可能误报或漏报，禁止自动 PASS |

## 问题轴 B：短时间重复表达与提炼

先按连续口播窗口分组，再分别标注重复类型：

- `LEXICAL_REPEAT`：同一词/短语短时间重复。
- `PARAPHRASE_REPEAT`：措辞不同但重复同一卖点或意思。
- `ADDITIVE_DETAIL`：主题相同，但后一次增加了有用证据、条件或体验细节，不应被误删。
- `NO_REPEAT`：内容不同。

对候选删减结果标注：

- `KEEP_BEST`：保留信息最完整、表达自然的一次；其他部分可删除且不损失必要信息。
- `KEEP_BOTH`：两次内容各有增量，或剪掉任一处都会破坏逻辑/自然衔接。
- `REVIEW`：语境或音频证据不足。

### 合成重复用例

| ID | 合成场景 | 预期判断 |
| --- | --- | --- |
| REP-01 | 同一短语连续重复两次，后一次没有增加信息 | LEXICAL_REPEAT；KEEP_BEST |
| REP-02 | 先泛称“很柔软”，后补充“贴肤但不闷” | ADDITIVE_DETAIL；KEEP_BOTH |
| REP-03 | 两种不同说法重复同一版型卖点，后一遍更完整 | PARAPHRASE_REPEAT；KEEP_BEST |
| REP-04 | 重复词是强调、犹豫或自然口语节奏的一部分 | REVIEW；不能仅凭重复词删除 |
| REP-05 | 删除重复句会使“它/这个/所以”等失去指代或因果对象 | KEEP_BOTH 或重选更大完整范围 |

## 最小记录格式

每个样例保存匿名 ID、代码与规则版本、切点/候选源区间、基线与实验版结果、机器风险信号、人工标签、证据来源和复核人。公开仓库只保存合成文本与脱敏聚合结果；真实素材、原始字幕、音频和真实商品信息留在本地受控工作区。

推荐对比项：吞字人工确认数、机器风险召回/误报（仅在有人工标签后计算）、重复表达人工确认数、增量细节误删数、最终保留内容完整性和人工自然度判断。样本不足时只列案例，不输出准确率或综合分数。

## 当前代码对应关系

- `scripts/refine_plans_v2.py` 已使用局部词级 ASR 边界与 20ms RMS dBFS 静音/连续能量信号调整切点。
- `scripts/refine_plans_v2.py::semantic_duplicate` 与 `scripts/audit_mimo_v2.py` 的同名逻辑用于跨文本/方案相似性检查；它们不等价于短时间口播重复检测，也不完成“保留最佳表达”的提炼。
- 因此第一轮实验应先测量现有规则在合成用例上的风险提示行为，确认误报/漏报边界，再单变量提出算法改动。当前没有真实素材接受测试的授权或样本标注，不作真实素材结论。

## 首轮合成核对记录

基线代码候选 `b994e42` 的隔离副本观察：

- 简单纯音在切点后持续到 0.50s、之后转静音；对 0.30s 结束点调用 RMS 精修后扩展到 0.54s，并把 `speech_continues_after_end` 标为 true。说明能量连续性分支按预期触发；纯音不能代表口播，也不能据此估计吞字检测效果。
- 一组合成词级时间戳中，粗起点 1.45s 被精修到 2.95s，因为后方 0.40s 间隔在当前评分中胜过更靠近粗起点的词边界。这个结果属于需要进一步构造反例和检查预期语义的风险信号：暂停位置可能导致剪掉粗范围开头的重要内容。
- `semantic_duplicate` 对五类同一短时口播内部的合成例子均返回 false。该函数本身用于两段候选/方案之间的比较，故此结果支持“当前路径没有显示短时重复提炼能力”，不构成算法缺陷证明。

以上为单次合成探针，不是测试套件、真实准确率或质量结论。下一步应固定重复表达的分组窗口/信息增量标签，并增加切点起点候选对照；在此之前不改精修评分。
