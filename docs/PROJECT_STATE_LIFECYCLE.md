# 项目状态与批次切片生命周期

## 目标结构

一个 DaVinci Resolve 项目对应唯一长期状态记录：

```text
.cache/projects/<project_key>/PROJECT_STATE.json
```

该记录使用稳定 Resolve 项目 ID 识别项目，并绑定一次经确认的素材目录、视频、字幕、标题表、源时间线和目标时间线。项目名称仅用于显示，不可作为唯一身份。新窗口和新商品批次都从此记录读取绑定信息。

批次是临时切片，放在项目目录下：

```text
.cache/projects/<project_key>/batches/<batch_id>/
```

批次状态只保留项目引用、商品 ID 范围、阶段进度、完成时间和该批派生产物。它不重新注册项目，也不保存另一份可独立编辑的素材路径/Resolve 绑定。变更项目素材路径必须显式更新项目级记录，并使依赖旧输入的批次证据失效。

## 保留与清理

- 批次开始时记录状态；完成时写入机器可读的 `completed_at` 时间。
- 仅已完成且已超过 7 天的批次可以清理。失败、运行中、暂停或没有可信完成时间的批次保留并报告原因。
- 清理器默认 dry-run，列出每个候选批次及其大小；真正删除须由显式 `--apply` 执行。
- 清理批次不得触及项目级 `PROJECT_STATE.json`、源素材、Resolve 项目、目标时间线或最终交付物。
- 仓库根目录旧 `PROJECT_STATE.json` 仅为迁移遗留，不参与项目识别或工作区选择。

## 迁移要求

当前工具链仍有按批次工作区读取 `PROJECT_STATE.json`/`PROJECT_CONFIG.json` 的旧入口。迁移实现必须统一经项目级注册表读取状态，并将批次写入改为批次状态文件；在所有读写入口完成迁移和回归前，不得宣称“一项目一记录”已在运行时生效，也不得自动删除旧记录或批次数据。
